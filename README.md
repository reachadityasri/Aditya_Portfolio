# Aditya Kumar Srivastava — Professional Portfolio

A responsive portfolio website built from the supplied resume.

## Run locally
1. Extract the ZIP archive.
2. Keep `index.html` and the `assets` folder together.
3. Open `index.html` in a modern browser.

No build step or package installation is required. The site uses plain HTML, CSS, and JavaScript. Google Fonts are loaded from the web; the page falls back to system fonts if unavailable.

## Included interactions
- Responsive navigation with active-section highlighting
- Light/dark theme toggle (preference is saved locally when browser storage is available)
- Resume download
- Email, phone, and LinkedIn links
- Skill category filters
- Scroll-reveal effects with reduced-motion support
- Back-to-top button and dynamic copyright year

## Content integrity notes
- Resume content is the source of truth.
- No project demos or repository URLs were supplied, so project cards are informational rather than dead links.
